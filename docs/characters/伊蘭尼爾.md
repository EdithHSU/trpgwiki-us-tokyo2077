# 伊蘭尼爾

!!! info ""
    受聖詠團派到東京的天使。他負責看守的裁決之書被[東京司法協會](../factions/東京司法協會.md)偷走，他是來收拾這個爛攤子的。

## 身分

伊蘭尼爾原本負責看守**裁決之書**，書中記載著對每個人的最終審判。東京司法協會偷走了這本書，用它牟取不義之財，聖詠團於是派他下凡，追回書並阻止協會。

他是一副刻板印象中的開朗外國人：穿夏威夷衫和夾腳拖。他最討厭這副近乎凡人的身體要用腳走路、要穿衣服；成為人類之後意外發現的樂趣是烈酒、雪茄，還有居酒屋巡禮。

象徵他的神的標記「裁決之雷」就在他的胸口。他的翅膀覆著羽毛，樣式簡約，散發著誘人、熟悉又憂鬱的氣息，平常藏起來就能偽裝成凡人。

## 敵者

東京司法協會由會長[伊佐治桂佑](../npcs/伊佐治桂佑.md)領導。伊蘭尼爾也懷疑，與協會敵對的[東京區域自治團體](../factions/東京區域自治團體.md)首領[犬山博久](../npcs/犬山博久.md)知道的比表面上更多；他是透過[綾目真理子](綾目真理子.md)認識犬山的。

## 人際

- **神田進次郎**：剛到東京時，他在街頭迷路，被[神田進次郎](神田進次郎.md)的黑頭車撞到。進次郎收留了沒有證件的他，讓他住了下來。他也救過進次郎的手下[中岡慎太郎](../npcs/中岡慎太郎.md)一命。進次郎的養子[神田司](../npcs/神田司.md)和他住在同一個屋簷下，他像大哥哥一樣照顧司。
- **綾目真理子**：[夢想家](../factions/夢想家.md)追殺真理子和她的養子時，他看到那個孩子和他熟悉的[神田司](../npcs/神田司.md)長得一模一樣，以為兩人是兄弟，便出手保護了真理子和整個[穹蒼之女](../factions/穹蒼之女.md)。
- **天邪**：他在[天邪](天邪.md)的俱樂部「[彼岸花](../places/彼岸花.md)」當男公關，但因為不會說謊，常讓客人下不了台。他認為奴役他人是錯的，決心在天邪墮落得更深之前拯救他。

## 開局

遊戲開始時，神聖的徵兆指向一個機會：東京司法協會的成員將舉行一場集會，他有機會擾亂甚至摧毀它。
