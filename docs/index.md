# 2077東京之影 團錄 Wiki

這裡整理了我們《城市之影》第二版（Urban Shadows 2E）「2077東京之影」戰役每一集的劇情，以及登場的角色、勢力與地點。2077 年的東京與日本其他地方幾乎隔絕，凡人、夜眷、能者與化外在這座城市裡爭奪權力與生存。

!!! note "整理中"
    目前收錄了兩次建角討論中確定的角色與勢力設定，正式劇情還沒有開始，也還沒有集數頁。
