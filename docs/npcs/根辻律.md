# 根辻律

!!! info ""
    [自維黨](../factions/自維黨.md)鴿派的領袖，79 歲。[宇佐美真司](宇佐美真司.md)的大學同學與秘密戀人，[神田進次郎](../characters/神田進次郎.md)在黨高層中仍然信任的人。

## 身分

根辻律是東武集團的御曹司（少爺），從大學時代就和真司認識，是真司的秘密戀人之一，也是[方舟](../factions/方舟.md)的成員，代號「信天翁」。大學畢業後，他和若宮朝陽一起從政，在政治界支援真司。

他和[茉莉](茉莉.md)同年，想替真司復仇。

## 現在

鴿派是被邊緣化的舊時代勢力。根辻律曾是黨的大老，如今年事已高，對進次郎來說比較容易操弄。
