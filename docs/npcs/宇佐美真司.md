# 宇佐美真司

!!! info ""
    新興宗教[創世紀](../factions/創世紀.md)的創辦人，宇佐美家的繼承人。已經過世。

## 身分

真司生於 1997 年，是[宇佐美惠子](宇佐美惠子.md)選定的繼承人，從母親手上接下了[宇佐美集團](../factions/宇佐美集團.md)的大部分股份。他在早稻田大學政經系結識的同學組成了小團體[方舟](../factions/方舟.md)，並在 2020 年代創立創世紀；在方舟裡，他的代號是「諾亞」（ノア）。

他的妻子是[茉莉](茉莉.md)，女兒是[宇佐美真理繪](宇佐美真理繪.md)，也是他選定的繼承人。他和母親一樣有許多情人與孩子，有男有女，[根辻律](根辻律.md)和方舟的幾名成員都是他的秘密戀人。

## 死後

真司與茉莉死後，宇佐美集團分裂成數間子企業，各方都自稱是真正理解他理念的人，爭奪正統。真理繪一面替父親復仇，一面製作魔偶。

[夢想家](../factions/夢想家.md)相信宇佐美家透過魔偶技術，保存了一個延續真司存在的副本。[穹蒼之女](../factions/穹蒼之女.md)做的「小真實」魔偶，外表都和他小時候一模一樣。
