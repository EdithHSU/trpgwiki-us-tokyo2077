# 神田司

!!! info ""
    [神田進次郎](../characters/神田進次郎.md)的養子，外表 12 歲的魔偶，裡面是一名吸血鬼的靈魂。

## 身分

司原本是一名一心向善的吸血鬼，在同族的鬥爭中落敗而被排擠，渴望脫離自己的肉體。進次郎說服[綾目真理子](../characters/綾目真理子.md)用危險魔法把他的靈魂移進一具空的魔偶，之後收他當養子。

這具魔偶和[穹蒼之女](../factions/穹蒼之女.md)的「小真實」是同一個型號，外表和[宇佐美真司](宇佐美真司.md)小時候一模一樣，但裡面沒有真司的人格。

## 人際

- [伊蘭尼爾](../characters/伊蘭尼爾.md)和他住在同一個屋簷下，像大哥哥一樣照顧他。看到長得一樣的[綾目真實](綾目真實.md)被追殺時，伊蘭尼爾以為是司的兄弟而出手相救。
