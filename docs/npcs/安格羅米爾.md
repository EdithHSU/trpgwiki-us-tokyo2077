# 安格羅米爾

!!! info ""
    [天邪](../characters/天邪.md)在地獄時的主人，一名魔鬼。

## 身分

安格羅米爾是一名「追求進化、不惜一切代價」的魔鬼。十年前他殺死了當時名叫塔基恩的天邪，天邪因此轉生到東京，和他斷了聯繫。

[綾目真理子](../characters/綾目真理子.md)用危險魔法召喚天使時出了差錯，召出的正是安格羅米爾。他要真理子說出天邪的下落作為代價，如今正要天邪立刻回到他身邊。

[伊蘭尼爾](../characters/伊蘭尼爾.md)決心阻止他再次奴役天邪。
