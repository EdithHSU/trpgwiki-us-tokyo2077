# 綾目真實

!!! info ""
    外表 12 歲的男孩魔偶，表面身分是[綾目真理子](../characters/綾目真理子.md)的養子。[夢想家](../factions/夢想家.md)認定他最可能是「真貨」。

## 身分

[穹蒼之女](../factions/穹蒼之女.md)已經研發出把人的靈魂放進魔偶的技術。為了保護「真實」，[宇佐美真理繪](宇佐美真理繪.md)做了一批外表和[宇佐美真司](宇佐美真司.md)小時候一模一樣的魔偶，巫團的每個人身邊都有一具。只有一具裝著真正的人格，其他都是 AI。

夢想家推測真理繪不會把真貨放在自己身邊，因此認定真理子身邊的這一具最可疑，想把他抓去研究創生的奧秘。

[神田司](神田司.md)也是同一批型號的魔偶，所以兩人長得一模一樣。
