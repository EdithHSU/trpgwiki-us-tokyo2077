# 茉莉

!!! info ""
    宇佐美茉莉，舊姓綾目。[宇佐美真司](宇佐美真司.md)有登記戶口的妻子，女巫組織[穹蒼之女](../factions/穹蒼之女.md)的創辦人。已經過世。

## 身分

茉莉出身香水商綾目家，父母過世後成為家族香水品牌的繼承人。她嫁給真司後改用夫姓，和真司是大學時代就認識的夥伴，也是[方舟](../factions/方舟.md)的成員，代號「白鴿」。夫妻倆各有各的事業。

她的親生女兒是[宇佐美真理繪](宇佐美真理繪.md)，養女是[綾目琉璃](綾目琉璃.md)。她把穹蒼之女傳給了真理繪；晚年則把綾目家的香水品牌交給琉璃打理。
