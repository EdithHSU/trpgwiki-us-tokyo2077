# 室町安夫

!!! info ""
    偏右保守政黨[守民黨](../factions/守民黨.md)的高層，夜眷出身。[天邪](../characters/天邪.md)經營的俱樂部[彼岸花](../places/彼岸花.md)的常客。

## 身分

室町是守民黨的地位 3 官員，是[自維黨](../factions/自維黨.md)陣營的對手。外表是個光頭、身材肥胖的中年大叔。

## 和天邪的關係

身為政客，他不能讓人知道自己流連彼岸花這種場所，這就是天邪握在手上的把柄。他欠了天邪 3 筆人情。
