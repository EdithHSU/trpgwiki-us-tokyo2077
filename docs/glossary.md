# 名詞表

有專頁的人物、地點與物品可從左側導覽進入；這裡收錄其他常出現的名詞。

## 世界與勢力

| 名詞 | 說明 |
| --- | --- |
| 2077 年的東京 | 與日本其他地方幾乎隔絕，電視、網路都和日本本土不通。傳說中的「龍」已經沉睡，年輕一代不知道舊時代的日本是什麼樣子 |
| 凡人、夜眷、能者、化外 | 城市裡的四個社群。凡人是一般人與獵人；夜眷是吸血鬼、狼人、幽靈等黑夜的存在；能者是巫師、女巫、神諭等施法者；化外是妖精、惡魔、天使等來自他界的存在 |
| 人情 | 欠下或握有別人的人情債，是城市裡最重要的交易籌碼 |
| 獵人協會 | 獵捕非凡人的組織 |
| 小真實 | [穹蒼之女](factions/穹蒼之女.md)做的一批男孩魔偶，外表都和[宇佐美真司](npcs/宇佐美真司.md)小時候一模一樣，只有一具裝著真正的人格 |
| 裁決之書 | 記載每個人最終審判的書，原本由天使[伊蘭尼爾](characters/伊蘭尼爾.md)看守，被[東京司法協會](factions/東京司法協會.md)偷走 |
| 鳳凰蛋 | 據說鳳凰出生時會認主。[鬼頭組](factions/鬼頭組.md)的奶奶想要它，蛋在[夢想家](factions/夢想家.md)手上 |
| 金色人魚 | [自維黨](factions/自維黨.md)黨部池中的生物，魚身人臉、會預言，吃了能長命百歲；被[天邪](characters/天邪.md)的人偷走煮來吃了 |
| 聖詠團 | 天使所屬的天界群體，派伊蘭尼爾來到東京 |
| 綾目家 | [茉莉](npcs/茉莉.md)的娘家，香水商，有加入創世紀；在能者之間以理性與智慧聞名 |
| 東武集團 | [根辻律](npcs/根辻律.md)家族的企業，他是集團的御曹司 |
