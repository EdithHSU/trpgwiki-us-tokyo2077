# 彼岸花

!!! info ""
    吸血鬼黑幫[鬼頭組](../factions/鬼頭組.md)底下的公關俱樂部，由[天邪](../characters/天邪.md)經營，是夜眷聚集、開會與享樂的地方。

## 店的樣子

彼岸花是一間有男公關與女公關的俱樂部，對所有社群的客人開放，但特別靠攏夜眷：夜眷會在這裡聚會、開會，享受彼岸花提供的娛樂。客人裡也有政界的有錢人。

## 生意

- **運送與販售異界生物**：天邪透過他工作的走私物流公司[黑羚運輸](../factions/黑羚運輸.md)進貨。
- **經營聚會場所**：讓夜眷在這裡聚集。

鬼頭組的奶奶[鬼頭祈](../npcs/鬼頭祈.md)想要一顆鳳凰蛋當彼岸花的鎮店之寶，天邪正為此和[綾目真理子](../characters/綾目真理子.md)合作。

## 員工

店裡的員工團隊各司其職：

- **保全**：一群吸血鬼，負責在門口決定誰能進場，有人鬧事時清場善後，也讓目擊者閉嘴。
- **馴獸師**：一群妖精，幾年前被當成珍奇異獸抓來東京，因為能和異獸溝通而被留下來照顧牠們，用勞動抵掉自己的身價。
- **內線**：一批欠下大筆賭債的凡人，潛伏在黑羚運輸裡。天邪定期塞錢給他們，他們把部分貨物登記成「運送損壞」，轉進彼岸花。
- **男公關**：天使[伊蘭尼爾](../characters/伊蘭尼爾.md)也在這裡上班。他不會說謊，客人問「我今天可不可愛」會老實回答「還好，妝有點太濃」，推薦酒時也會說「都不太好喝」，是個很難教的新人。

## 常客

- [室町安夫](../npcs/室町安夫.md)：[守民黨](../factions/守民黨.md)的高層，夜眷出身。因為不能讓人知道自己流連這種場所，欠了天邪 3 筆人情。
- [神田進次郎](../characters/神田進次郎.md)：私下來這裡和吸血鬼交朋友。

## 對手

同樣從地獄轉生來的惡魔[修羅](../npcs/修羅.md)，在對面開了同類型的俱樂部「石蒜」，自稱「我才是正宗」，正一步步侵蝕彼岸花的市場。
