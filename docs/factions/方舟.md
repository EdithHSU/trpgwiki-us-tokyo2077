# 方舟

!!! info ""
    [宇佐美真司](../npcs/宇佐美真司.md)在早稻田大學政經系時期結識的同學所組成的小團體，[創世紀](創世紀.md)的經營中樞。

## 組織

創世紀的初始成員就是方舟。方舟的成員各有代號，大多取自鳥類；他們和真司出社會後結識的某些超自然存在處得不好。

## 成員

| 成員 | 社群・扮演書 | 代號 | 說明 |
| --- | --- | --- | --- |
| [宇佐美真司](../npcs/宇佐美真司.md) | 能者・聖人 | 諾亞（ノア） | 創世紀的年輕領導人 |
| [茉莉](../npcs/茉莉.md) | 化外・容器 | 白鴿 | 真司有登記戶口的妻子 |
| [根辻律](../npcs/根辻律.md) | 凡人・察覺者 | 信天翁 | 東武集團的御曹司，真司的秘密戀人 |
| 若宮朝陽 | 凡人・察覺者 | 蒼鷹 | 政治世家若宮家的么子，和真司一直維持著「朋友以上、戀人未滿」的關係；代號來自若宮家的家紋 |
| 岸本湊 | 凡人・學者 | 角鴞 | 創世紀的幹部，管控金流；名義上是真司的秘密戀人，本人認為比較像各取所需。所有吃力不討好的工作都由他負責，讓真司能自由發揮 |
| 上妻留依 | 能者・巫師 | 丹頂鶴 | 古老神道世家的女巫，真司的秘密戀人 |
| 大野透 | 夜眷・狼人 | 灰狼（グレイウルフ） | 隸屬於創世紀的狼人，領地在南麻布十番。原本臥底進創世紀要暗殺真司，失敗後反被真司馴服，成了他的戀人 |
| 河井新太 | 能者・巫師 | — | 巫師酒吧的倖存者，在狼人酒吧工作，深受真司的教義吸引而加入創世紀 |

除了狼人大野透，當年的方舟都是早稻田大學時期的小圈圈。根辻律與若宮朝陽大學畢業後從政，在政治界支援真司。
