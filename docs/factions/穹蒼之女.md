# 穹蒼之女

!!! info ""
    [茉莉](../npcs/茉莉.md)創立、傳給女兒[宇佐美真理繪](../npcs/宇佐美真理繪.md)的女巫組織。[綾目真理子](../characters/綾目真理子.md)所屬的巫團。

## 理念

成員清一色是女性，相信「愛能跨越一切的藩籬」，為了守護凡人在東京的安寧而努力，也因此常被掌權者找麻煩。她們不參與政黨活動，認為檯面上的政黨已經走偏。徽記是塔羅牌「星星」的符號。

對外，穹蒼之女是一個規模很小的婦女互助組織，屬於[創世紀](創世紀.md)的分支，但獨立於[宇佐美集團](宇佐美集團.md)之外。

## 成員

巫團是「尋得的家人」：她們通常是幫助一名有天賦的女巫脫離困境之後，對方便加入成為家人。成員之間大多沒有血緣，卻視彼此為家人，互不虧欠，有需要時也不會拒絕彼此。

- [宇佐美真理繪](../npcs/宇佐美真理繪.md)：首領，唯一和茉莉有血緣關係的人。
- [綾目琉璃](../npcs/綾目琉璃.md)：茉莉的養女。
- [綾目真理子](../characters/綾目真理子.md)：琉璃的養女。
- 若宮晴花（23 歲）：巫團幫她逃離了不想要的婚姻。
- 澤城美由紀（35 歲）：巫團幫她離了婚。
- 黑澤雙葉（40 歲）：遺傳學學者。

## 魔偶技術

穹蒼之女握有宇佐美集團的核心魔偶技術與鍊金術奧秘，已經能把人的靈魂放進魔偶。成員身邊各有一具外表和[宇佐美真司](../npcs/宇佐美真司.md)小時候一模一樣的「小真實」魔偶，只有一具裝著真正的人格。

## 敵人

巫師團體[夢想家](夢想家.md)渴望竊取她們的知識與魔法，曾把她們追殺到幾乎滅絕。[伊蘭尼爾](../characters/伊蘭尼爾.md)曾出手保護過她們。
