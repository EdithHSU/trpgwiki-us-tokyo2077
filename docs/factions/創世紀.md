# 創世紀

!!! info ""
    [宇佐美真司](../npcs/宇佐美真司.md)在 2020 年代創立的新興宗教，標榜「愛無法分隔彼此」。東京最大的組織，旗下分出許多組織。

## 理念

創世紀致力於幫助性少數族群，也吸收了許多左派思想的年輕人。因為[宇佐美集團](宇佐美集團.md)在社經界的地位，創世紀和許多政商名流都有往來。

## 方舟

創世紀的經營中樞是[方舟](方舟.md)：真司在早稻田大學政經系時期結識的同學所組成的小團體，也是創世紀的初始成員。

## 旗下組織

- [自維黨](自維黨.md)：源自創世紀的政黨。
- [穹蒼之女](穹蒼之女.md)：[茉莉](../npcs/茉莉.md)創立的女巫組織，獨立於宇佐美集團之外。
- 香水商綾目家（茉莉的娘家）也加入了創世紀。

## 現況

真司失蹤後，創世紀現在真正的領導人還沒有定論。宇佐美集團分裂成數間子企業，各方都自稱是真正理解真司理念的人，爭奪正統；自維黨內部也派系鬥爭不斷。

[神田進次郎](../characters/神田進次郎.md)約十年前經由[宇佐美真理繪](../npcs/宇佐美真理繪.md)進入了創世紀的核心圈。
