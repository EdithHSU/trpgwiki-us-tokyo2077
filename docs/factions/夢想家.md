# 夢想家

!!! info ""
    追殺[穹蒼之女](穹蒼之女.md)的巫師團體，想奪取她們的魔偶技術。

## 目的

夢想家相信宇佐美家透過魔偶技術，保存了一個延續[宇佐美真司](../npcs/宇佐美真司.md)存在的副本，想把魔偶抓去研究創生的奧秘。他們認定[綾目真理子](../characters/綾目真理子.md)身邊的[綾目真實](../npcs/綾目真實.md)最可能是真貨。

## 成員與據點

成員中有一名宇佐美家的人，但還沒有任何具體的 NPC 現身。夢想家和東京迪士尼樂園有關聯，鳳凰蛋就放在他們那裡，對他們正在進行的儀式十分重要；[天邪](../characters/天邪.md)與真理子正計畫把它奪走。
