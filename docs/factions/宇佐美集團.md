# 宇佐美集團

!!! info ""
    宇佐美ケミカルグループ。[宇佐美惠子](../npcs/宇佐美惠子.md)創立的財閥，[宇佐美真司](../npcs/宇佐美真司.md)與[茉莉](../npcs/茉莉.md)死後分裂成數間子企業。

## 事業

集團的事業涵蓋化學製品與高機能材料、農業與蜂業、生物科技與製藥，以及相關的技術研發、海外市場拓展與全球商業布局。集團的核心魔偶技術與鍊金術奧秘，則由[穹蒼之女](穹蒼之女.md)掌握。

## 繼承

惠子退休後，把大部分股份轉給她選定的繼承人真司，另有幾間子公司分給她的其他孩子。真司選定的繼承人是女兒[宇佐美真理繪](../npcs/宇佐美真理繪.md)。

## 現況

真司與茉莉死後，集團分裂成數間子企業，不願服從崇尚左派思想的真理繪。真理繪握有自己的 AI 公司，正和集團裡其他打著真司名號的人爭奪正統。惠子與真司都有許多情人與孩子，這些人或他們的後代，也可能出來爭奪繼承權。
