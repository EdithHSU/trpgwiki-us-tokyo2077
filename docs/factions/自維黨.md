# 自維黨

!!! info ""
    正式名稱「自由維新黨」，源自[創世紀](創世紀.md)的凡人政黨，正與吸血鬼全面對抗。[神田進次郎](../characters/神田進次郎.md)所屬的政黨。

## 立場

自維黨整體是激進的左派政黨，支持同性婚姻與多元成家，據點在港區。現任領導層則以強烈反吸血鬼為賣點，對吸血鬼發動全面戰爭，黨內派系鬥爭不斷。

創世紀的方舟成員根辻律與若宮朝陽，大學畢業後就從政支援[宇佐美真司](../npcs/宇佐美真司.md)。

## 派系

- **鷹派**：現任領導人[若宮竹虎](../npcs/若宮竹虎.md)，口號是「打擊犯罪」，實際上要武裝人民、攻打吸血鬼。
- **鴿派**：被邊緣化的舊時代勢力，領袖是[根辻律](../npcs/根辻律.md)；前總管[安倍謙三](../npcs/安倍謙三.md)也屬於鴿派。
- **激進改革派**：[內田早苗](../npcs/內田早苗.md)與神田進次郎所屬的派系，為了擴大黨的影響力不擇手段。

## 對手

偏右的保守政黨[守民黨](守民黨.md)。

## 金色人魚

黨部的池子裡，從宇佐美真司的時代就養著一條「金色人魚」：魚的身體、像人的臉，據說會預言，吃了它的肉能長命百歲。[天邪](../characters/天邪.md)的人把它偷走煮來吃了，進次郎說服黨的領導層寬恕了對方。
